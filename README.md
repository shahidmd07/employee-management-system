# Employee Management System (EMS)

## Requirements
- Node.js LTS
- MySQL 8.x and MySQL Workbench
- VS Code

## 1. Create the database
1. Open MySQL Workbench and connect to your local MySQL server.
2. Open `database.sql`.
3. Execute the complete script.
4. If you already have an older `ems_db`, back it up first. Run the `ALTER TABLE` statement in the SQL comments to add the `Cancelled` leave status, then execute the attendance table creation statement.

## 2. Configure the project
1. Extract this folder.
2. Open the `EMS-New` folder in VS Code.
3. Open the terminal in VS Code.
4. Run:

```bash
npm install
```

5. Copy `.env.example` and rename the copy to `.env`.
6. Open `.env` and enter your local MySQL password in `DB_PASSWORD`.
7. Set a long private value for `SESSION_SECRET`.

## 3. Run the project

Development mode:

```bash
npm run dev
```

Or normal mode:

```bash
npm start
```

Open `http://localhost:3000`.

## 4. First-time setup
1. Open Admin Setup and create the one-time admin account.
2. Log in as Admin.
3. Add employee records.
4. Log out and register an employee account using an Employee ID created by Admin.
5. Log in as Employee and test leave and attendance features.

## Features
- Admin and Employee login
- One-time Admin account setup
- Employee registration using Admin-created Employee ID
- Add, update, view and remove employees
- Leave application, approval, decline and cancellation of pending requests
- Employee attendance check-in/check-out
- Attendance history and monthly summary
- Admin attendance search and date/month filtering
- Change password and logout

## Attendance rules
- One attendance record per employee per date.
- Check In and Check Out times are recorded by MySQL.
- Check Out is enabled only after Check In.
- A completed day is `Present`; a day without Check Out remains `Incomplete`.
- No manual attendance editing, GPS, biometrics, shift, late or overtime rules.

## Notes
- `.env` is local and must not be shared or committed.
- `node_modules` and `package-lock.json` are generated by `npm install`.
- This project uses the existing visual style stylesheet and a matching EJS layout.
